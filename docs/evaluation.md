# Evaluation protocol

The evaluator runs without a model key or external service. It tests the system behavior that should remain stable when an OCR or multimodal model is added later.

- **Extraction:** five synthetic entities must be typed, located, and linked to source text.
- **Revision comparison:** the instrument replacement must report both addition and deletion.
- **Validation:** an unresolved branch must become a blocking dangling-connection issue.
- **Q&A:** a tag-based question must return a relationship path and source evidence.
- **Abstention:** an unsupported question must require human review instead of inventing an answer.

This is a software and contract evaluation, not a claim of production P&ID recognition accuracy.
